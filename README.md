# Main Place, лаунж-бар в Куюках

Сайт заведения: главная с живыми отзывами, «Что нового» с афишей и видео, меню с корзиной, пробная оплата,
бронь стола на схеме зала. Next.js 16, React 19, TypeScript, обычный CSS.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

## Где что лежит

- `src/lib/data.ts`: контакты, часы, меню с ценами, скидки, афиша, видео, фото зала.
- `src/lib/reviews.ts` и `src/app/api/reviews/route.ts`: отзывы с Яндекс Карт. Сервер спрашивает Яндекс не чаще
  раза в 5 минут, открытая страница перепроверяет отзывы каждые 5 минут. Если Яндекс не ответил, видна копия из
  `src/lib/saved-reviews.json`.
- `src/components/floor-plan.tsx`: схема зала, столы в массиве `spots`.
- `src/components/booking.tsx`: календарь, часы, занятость, форма.
- `src/app/checkout/page.tsx`: пробная оплата.
- `src/app/shards.css`: формы колотых плит для фото.
- `src/components/forge.tsx`: первый экран (контур треугольника, удар печати, искры).
- `src/lib/shatter.ts`: разлом стены перед фотографией.
- `src/app/foto`: фото заведения по темам, список в `photoGroups`.

## Что заменить перед запуском

- Telegram: поле `telegram` в `data.ts`. Сейчас там адрес из карточки Яндекса (`mainplace_kuyuki`). Если это канал,
  впишите логин администратора, чтобы кнопки открывали личный чат.
- Бронь хранится в браузере гостя, занятость столов имитируется. Нужна CRM, бот или таблица.
- Оплата ничего не списывает. Подключите ЮKassa, CloudPayments или другой эквайринг.
- Схема зала придумана по фотографиям: сверьте столы и число мест.
- Цены на кальяны, чай и бар на Яндексе не указаны, в меню их нет.
- Правила скидок (документ в день рождения, полное списание 1000 бонусов, удержание стола 15 минут) согласуйте с заведением.
